## ✨ Core Features

| Feature | Description |
| --- | --- |
| Interactive CLI browser | Numeric entry, dir nav, back, home, multi-select, hidden toggle |
| Two read modes | `path` only / `copy` into work dir |
| Extension filter | Single / multiple / no limit |
| File manager | read-only / read-write; delete / copy / cut / paste / rename / open / attrs |
| Free file naming on save | Only when saving a single file |
| Windows partitions | Includes letter-less volumes; press `g` anywhere |
| Language packs | Built-in zh_CN / en; others loaded from `lg/*.txt` on demand |
| Debug switch | `ts.txt` controls log saving and `force_language` |
| Auto elevation | Windows UAC / Android root / Linux sudo-su |
| Run directly | `python cfdialog.py` opens the file manager (read-write) |

## 🚀 Quick Start

### Requirements

- Python ≥ 3.8
- Standard library only (no third-party runtime deps)

### Example

```python
from cfdialog import (
    pick_file, pick_folder, save, file_manager,
    set_language, get_language,
)

p = pick_file(mode="path")

ps = pick_file(multiple=True, mode="copy", work_dir="./imported",
               extensions=[".txt", ".md"])

d = pick_folder()

out = save("report.txt", free_name=True)

save(["a.txt", "b.txt"], mode="copy")

file_manager(access="readwrite")     # or access="readonly"

print(get_language())                # e.g. "zh_CN"
set_language("ja")
```

### Run directly

```bash
python cfdialog.py
```

Opens the file manager in read-write mode, starting from the current working directory.

## 🔑 Core API

```python
pick_file(multiple=False, mode="copy", work_dir=None,
          start_dir=None, extensions=None, overwrite=False,
          show_hidden=False, prompt=None, lang=None)

pick_folder(multiple=False, mode="path", work_dir=None,
            start_dir=None, show_hidden=False,
            prompt=None, lang=None)

pick(select="file", multiple=False, mode="path",
     work_dir=None, start_dir=None, extensions=None,
     overwrite=False, show_hidden=False,
     prompt=None, lang=None)

save(sources=None, target_dir=None, mode="path",
     work_dir=None, free_name=False, default_name=None,
     overwrite=False, on_progress=None,
     start_dir=None, show_hidden=False,
     prompt=None, lang=None)

file_manager(start_dir=None, access="readwrite",
             show_hidden=False, prompt=None, lang=None)
```

Return conventions:

| Function | Single | Multiple | Cancel |
| --- | --- | --- | --- |
| `pick_file(mode='path')` | `Path` | `List[Path]` | `BrowserCancelled` |
| `pick_file(mode='copy')` | `Path` (copy) | `List[Path]` | `BrowserCancelled` |
| `pick_folder()` | `Path` | `List[Path]` | `BrowserCancelled` |
| `save(mode='path')` | `Path` (dir) | — | `None` |
| `save(mode='copy')` | `Path` (copy) | `List[Path]` | `None` |
| `file_manager()` | `None` | — | — |

## 🗂 File Manager

```python
file_manager(access="readonly")     # disables rm / ct / ps / rn / at
file_manager(access="readwrite")    # everything
```

Read-only still allows **copy to in-memory clipboard** (`cp`) and **open** (`op`), but disables all disk-mutating actions.

## 🌐 Language Packs

Priority (high → low):

```
ts.txt force_language  →  per-call lang=  →  set_language()  →  detect_language()  →  en
```

Only `zh_CN` / `en` are built-in. Other codes are loaded from `lg/<code>.txt` on demand and fall back to English if missing. Pack format:

```text
# code=de
# name=Deutsch
# name_en=German
# native_name=Deutsch

prompt_folder=Ordner auswählen
prompt_file=Datei auswählen
```

Runtime registration:

```python
from cfdialog import register_language, set_language
register_language("de", {"prompt_folder": "Ordner auswählen"})
set_language("de")
```

## ⚙️ Debug Switch

`ts.txt`:

```ini
log=true
log_dir=log
force_language=zh_CN
```

- `log`: enable logging into `log/YYYYMMDD.txt`
- `log_dir`: relative to the library dir
- `force_language`: overrides every other language source; `none` or empty = not forced

Call `reload_debug_config()` after editing.

## 💽 Partitions

On Windows, includes drive letters (C:, D:, …) and **letter-less volumes**. Press `g` on any page to open the partition chooser.

```python
from cfdialog import list_partitions
for p in list_partitions():
    print(p["name"], p["path"], p["label"], p["type"])
```

## ❓ FAQ

**Q1. Why does Android auto-elevation kill the program?**
`su -c` spawns a new root process; the parent `sys.exit(0)` makes the original terminal appear "done". Recommended: `set_auto_elevate(False)` on Android and elevate manually when needed.

**Q2. Which dir do relative paths resolve against?**
`Path.cwd()` — the run dir, not the script dir. Use `os.chdir()` if needed.

**Q3. Why is the extension filter not applied to directories?**
So users can navigate into subdirs to find matching files. Filtering dirs would break navigation.

**Q4. What if a language pack is missing?**
Fallback to English, no exception. Load attempts are logged if logging is on.

**Q5. Why is `cp` allowed in read-only mode?**
`cp` only stores picks in the in-memory clipboard. `ps` actually writes to disk, so it is disabled.
